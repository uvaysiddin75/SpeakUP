# SpeakUp UI sounds

Drop short, soft MP3 files here to override Web Audio synthesis:

- `correct.mp3`
- `wrong.mp3`
- `achievement.mp3`
- `level-complete.mp3`
- `recording-start.mp3`
- `recording-stop.mp3`

Until files exist, SpeakUp uses generated Web Audio tones.
Do not commit copyrighted audio.
